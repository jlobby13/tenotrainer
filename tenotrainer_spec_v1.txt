1. SYSTEM OBJECTIVE
Build
A web application that functions as a clinical decision support and coaching system for Achilles tendinopathy rehabilitation.
Goal
To:
•	Generate personalized, rule-based rehab programs 
•	Adapt programs dynamically based on response to load 
•	Provide clear coaching guidance 
•	Deliver evidence-backed rationale using a curated knowledge base 
•	Support clinician oversight for complex decisions 
Generate and adapt personalized Achilles tendon loading programs based on structured user data, while providing clear coaching guidance, progress tracking, and evidence-based rationale using a curated internal knowledge base.

11.1 Core Distinction
Rehab Stage = Loading Strategy Axis (WHAT)
Defines:
•	type of loading 
•	mechanical stimulus 
•	progression pathway 
NOT symptom-driven directly
________________________________________
Irritability = Load Tolerance Modifier (HOW MUCH / HOW FAST)
Defines:
•	volume 
•	intensity 
•	frequency 
•	progression speed 
Symptom-response driven
________________________________________
11.2 REHAB STAGE = LOADING PROFILE SYSTEM
Stage 1 — Capacity Initiation
Loading:
•	isometrics 
•	slow isotonic 
Purpose:
•	introduce load 
•	reduce sensitivity 
________________________________________
Stage 2 — Strength Development
Loading:
•	concentric/eccentric 
•	eccentric-biased 
•	heavy slow resistance 
Purpose:
•	build tendon capacity 
________________________________________
Stage 3 — Energy Storage & Release
Loading:
•	fast dynamic 
•	reactive strength 
•	plyometrics 
•	explosive strength 
Purpose:
•	restore elastic function 
________________________________________
Rule
Stage progression = capacity-driven
